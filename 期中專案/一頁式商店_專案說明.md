## 一、專案簡介

本專案為一個**一頁式購物網站**，名為「程式人商店」，專為程式設計師設計，販售程式相關的主題商品（T恤、馬克杯、貼紙等）。  
所有操作皆可在**同一頁面**完成：瀏覽商品 → 加入購物車 → 查看購物車 → 填寫資料結帳，無須跳轉頁面，提供流暢的購物體驗。

---

## 二、使用技術

| 技術 | 用途 |
|------|------|
| **Next.js 16** (App Router) | 全端框架，同時負責前端畫面與後端 API |
| **React 19** | 前端 UI 元件化 |
| **Tailwind CSS v4** | 原子化 CSS，快速開發響應式介面 |
| **JavaScript** | 程式語言 |

### 為什麼選 Next.js？

- 前後端合一：不需分別建置前端 + 後端專案
- API Routes：可直接在專案內撰寫 RESTful API
- 開箱即用：file-based routing、自動 code splitting
- 部署容易：可一鍵部署到 Vercel 等平台

## 三、功能介紹

### 一般使用者

1. **商品展示**
   - 6 項程式主題商品，以卡片網格呈現
   - 每個商品有 emoji 圖示、名稱、價格、描述

2. **購物車**
   - 點擊「加入購物車」按鈕即可加入
   - 重複加入同一商品會累積數量
   - 右側滑入式購物車抽屜，不影響主頁瀏覽
   - 可調整數量（透過重複加入）或移除商品
   - 即時計算總金額

3. **結帳**
   - 在購物車抽屜內填寫姓名、Email、電話
   - 送出訂單後顯示成功訊息
   - 表單驗證（必填欄位）

4. **響應式設計**
   - 電腦：3 欄商品網格
   - 平板：2 欄
   - 手機：1 欄

### 管理員（訂單管理）

- 獨立 `/admin` 頁面
- 檢視所有訂單（依時間倒序排列）
- 顯示訂單編號、客戶資訊、下單時間、商品明細
- 手動重新整理訂單列表

## 五、API 設計

| 方法 | 路徑 | 說明 | 請求體 | 回應 |
|------|------|------|--------|------|
| GET | `/api/products` | 取得所有商品 | — | 商品陣列 |
| GET | `/api/orders` | 取得所有訂單（管理用） | — | 訂單陣列 |
| POST | `/api/orders` | 建立新訂單 | `{ name, email, phone, items[] }` | 建立之訂單 + 201 |

### `POST /api/orders` 請求範例

```json
{
  "name": "王小明",
  "email": "abc@example.com",
  "phone": "0912-345-678",
  "items": [
    { "productId": 1, "name": "\"Hello World\" 經典T恤", "price": 490, "quantity": 2 },
    { "productId": 3, "name": "\"CSS is Awesome\" 貼紙包", "price": 120, "quantity": 1 }
  ]
}
```

### `POST /api/orders` 回應範例

```json
{
  "id": 1,
  "name": "王小明",
  "email": "abc@example.com",
  "phone": "0912-345-678",
  "items": [...],
  "createdAt": "2026-06-13T09:00:00.000Z"
}
```

## 六、資料流程

```
使用者瀏覽頁面
    │
    ├── fetch /api/products ← server 讀取 products.js
    │
    ├── 點擊「加入購物車」→ React state 更新 cart
    │
    ├── 點擊購物車圖示 → 開啟 CartDrawer（滑入）
    │
    ├── 填寫表單 → 點擊「送出訂單」
    │      │
    │      └── POST /api/orders
    │             │
    │             └── server 儲存至記憶體（store.js）
    │
    ├── 顯示訂單成功訊息
    │
    └── 管理員至 /admin 檢視訂單
           │
           └── fetch GET /api/orders
```

## 七、前端狀態管理

使用 React `useState` / `useEffect` 進行狀態管理：

| 狀態 | 類型 | 所在元件 | 說明 |
|------|------|----------|------|
| `products` | `Array` | `page.js` | 商品列表，從 API 載入 |
| `cart` | `Array<{product, quantity}>` | `page.js` | 購物車內容 |
| `isCartOpen` | `boolean` | `page.js` | 購物車抽屜開關 |
| `orderStatus` | `'idle' | 'submitting' | 'success'` | `page.js` | 訂單狀態 |
| `form` | `{name, email, phone}` | `CartDrawer.js` | 結帳表單 |

## 九、專案特色

1. **真正的一頁式體驗**  
   瀏覽、購物車、結帳全部在首頁完成，購物車以滑入式抽屜呈現，不中斷瀏覽流程。

2. **全端整合**  
   Next.js 同時負責前端渲染與後端 API，展示現代全端開發模式。

3. **響應式設計**  
   使用 Tailwind CSS 的 grid 系統，自動適應不同螢幕尺寸。

4. **元件化架構**  
   將 UI 拆分為 ProductCard、CartDrawer 等獨立元件，程式碼易於維護與擴充。

5. **RESTful API**  
   前後端透過標準 HTTP API 溝通，架構清晰。
